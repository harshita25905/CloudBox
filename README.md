# CloudBox

Secure File Sharing API built with FastAPI.

## Features
- JWT Authentication
- User Registration & Login
- PostgreSQL
- SQLAlchemy ORM
- Alembic Migrations
- Password Hashing (bcrypt)
- REST APIs

## Tech Stack
- FastAPI
- PostgreSQL
- SQLAlchemy
- Alembic
- Pydantic
- JWT
- Passlib
